# Week 3 Assignment: Pandas Data Cleaning and Visualization

## Project Overview
This project demonstrates data cleaning and exploratory data analysis using Python. The dataset contains exercise information, including duration, date, pulse, maximum pulse, and calories.

## Objectives
- Inspect and understand the dataset using Pandas.
- Identify and handle missing values.
- Remove duplicate records.
- Standardize date formats.
- Filter rows based on relevant conditions.
- Create new columns for additional analysis.
- Visualize data using Matplotlib and Seaborn.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files
- `Pandas_Data_Cleaning.ipynb` — notebook containing the code, analysis, and visualizations.
- `week3_data.csv` — original dataset.
- `cleaned_week3_data.csv` — cleaned dataset.
- `filtered_week3_data.csv` — filtered dataset used for analysis.

## Key Tasks
1. Data inspection and quality checks.
2. Duplicate removal and missing-value handling.
3. Date standardization.
4. Feature creation and row filtering.
5. Data visualization and correlation analysis.
6. Exporting the processed datasets.

## How to Run
1. Download or clone this repository.
2. Install the required packages:

   `pip install pandas numpy matplotlib seaborn jupyter`

3. Place the notebook and original CSV file in the same directory.
4. Open the notebook in Jupyter Notebook.
5. Run the cells in order.

## Conclusion
This project demonstrates fundamental data-cleaning, transformation, and visualization techniques using Python libraries. It highlights the importance of checking data quality before performing analysis.
